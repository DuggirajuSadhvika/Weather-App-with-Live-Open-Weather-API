# Weather App with Live OpenWeather API

## Project Description
The Weather App is a Python-based application that fetches real-time weather information for a given city using the OpenWeather API. It displays important weather details such as temperature, humidity, and weather conditions. The application uses Python Requests to communicate with the API and JSON parsing to process the response.

## Features
- Enter any city name to check its weather.
- Fetch real-time weather data using the OpenWeather API.
- Display current temperature.
- Display humidity levels.
- Show weather conditions and descriptions.
- Handle invalid city names and API errors.
- Display weather information through a command-line interface (CLI).

## Technologies Used
- Python
- Requests Library
- OpenWeather API
- JSON
- VS Code

## How to Run
1. Install Python on your system.
2. Install the required library:
   `pip install requests`
3. Create an account on OpenWeather and generate an API key.
4. Add your API key to the Python script.
5. Download or clone the project.
6. Open the project folder in VS Code.
7. Run the Python script.
8. Enter a city name to view its current weather information.

## API Integration
This project uses the OpenWeather API to retrieve live weather information. The API returns data in JSON format, which is parsed using Python to extract temperature, humidity, and weather descriptions.

## Error Handling
- Handles invalid city names.
- Handles invalid API keys.
- Handles network connection errors.
- Handles unsuccessful API responses.
